# richarddavenport/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install richarddavenport/tap/swarmctl
```

| formula | what it is |
|---|---|
| `swarmctl` | terminal UI for Docker Swarm — [binaries](https://github.com/richarddavenport/swarmctl-dist) |

Formulae install prebuilt binaries rather than building from source, because the
source repositories are private and a formula can only fetch what needs no
credential.
